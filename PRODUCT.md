# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

People using coding agents such as Codex and Claude Code who want to make and revise multimedia. The user approved this audience and the studio-led relaunch proposal on 2026-09-30.

## Product Purpose

Slopcamera lets a coding agent make images, diagrams, animation, 3D scenes, and video from source files it can keep revising. The website helps someone see the possible results, understand how to direct a useful revision, install the tools, and finish a first project.

## Positioning

A multimedia studio for a coding agent. Source files, deliberate creative direction, and repeatable edits connect the finished work to the process that made it. Impeccable is an inspiration for teaching a useful vocabulary through visible results; Slopcamera's subject is multimedia creation.

## Operating Context

The canonical local CLI and Agent Skill work with authored scenes and media projects. Some workflows require local engines or a hosted generation provider. The website is a static public introduction and documentation site, with no browser account or credential entry. The installation guide and release records define the current supported distribution.

## Capabilities and Constraints

- Films and animation, still images and diagrams, native 3D scenes, visual explanations, and editing imported footage are supported through their documented workflows.
- Native renderers and paid model providers have distinct prerequisites. State requirements beside relevant examples and instructions.
- Retain editable source and relevant runtime facts for demonstrated outputs. Public media must pass the repository's existing asset and review checks.
- The current public token benchmark does not substantiate token or cost savings. Do not make those promises.
- Keep local media, private project metadata, credentials, and unpublished provider payloads out of public source and distribution.

## Brand Commitments

The user requested imaginative, sometimes absurd concepts executed with strong motion design, graphic design, illustration, and CG craft. Finished work should make the breadth and possible polish of Slopcamera immediately visible. Public prose stays factual and direct; the artwork carries the surprise.

## Evidence on Hand

The maintained examples, source registries, capability documentation, and style portfolio are evidence of current functionality. New relaunch films begin as proposed productions and become public evidence only after rendering and review. Do not invent customer endorsements, production measurements, benchmarks, or provider prices.

## Product Principles

- Let finished work establish the creative standard.
- Teach directing decisions with visible, reproducible changes.
- Give each example a useful path from the brief to editable source.
- Explain prerequisites when they affect the reader's next action.

## Accessibility & Inclusion

Preserve keyboard access, semantic structure, readable contrast, forced-colors behavior, and reduced-motion preferences. Offer sound on demand and useful text context for visual work. Essential content and source links must remain available without JavaScript.
