Your tools. Your files.

Slopcamera keeps editable source beside each render. Original recordings and imported media stay unchanged. There is no Slopcamera account or hosted project database.

Start with the Agent Skill for Codex or Claude Code. Use the CLI, TypeScript SDK, or fixed MCP toolset in your own workflows. MCP does not expose every CLI command.

Local renders use the tools on your machine. Model generation uses your Vercel AI Gateway account, or prepaid Hraness Credits for hosted image generation. Media uploads require acknowledgement.

Native engines install separately. Native Python jobs require --allow-trusted-code; they and custom Bun workflows run as your current user, without an operating-system sandbox. Review their source first. Read the security policy, privacy guide, and platform requirements.

Common questions

How is Slopcamera different from Remotion or HyperFrames?

Remotion renders React to video; HyperFrames renders HTML. Slopcamera combines HTML motion, diagrams, 3D and native scenes, and edits of your own footage in a local project. Compare their workflows and licensing, or read SlopCamera vs Remotion and SlopCamera vs HyperFrames.

Do I need to write code?

Describe the result to your coding agent; it writes the source and runs the commands.

Does Slopcamera require an account or subscription?

No. Slopcamera has no account or subscription. Generation uses your own Vercel AI Gateway account, or prepaid Hraness Credits for hosted image generation.

What does it cost?

Slopcamera is free; editing, diagrams, vectorization, and exports run locally. Model usage is billed to your Vercel AI Gateway account, or to prepaid Hraness Credits for hosted image generation.

Which platforms does Slopcamera run on?

Use Bun 1.3.14+ on macOS, Linux, or Windows. A few features are narrower: vectorization, local audio and color effects, and the native engines (Blender, CadQuery, and Manim) run on macOS and Linux. Native HTML rendering, GPU scene profiles, and face analysis need macOS. Import existing recordings; Slopcamera does not record your screen or camera. Run slopcamera doctor to check local tools and see the platform requirements.

Does Slopcamera overwrite original media?

Edits leave original recordings and imported media unchanged. Diagram renders replace only their named derived outputs.

When can local media leave the machine?

Editing and rendering stay local. Gateway generation and selected cloud analysis upload named media only after acknowledgement. Native Python and custom Bun workflows run with current-user access, including possible network access.

Which agents can use the skill, and how do I install it for Claude Code?

Use Codex, Claude Code, or an agent that reads ~/.agents/skills. Run slopcamera skill install for Codex, add --target claude for Claude Code, or --target agents for other agents.

Is Slopcamera the same as Atet?

Yes. Atet was renamed Slopcamera in September 2026, and atet.sh now redirects here. Old Atet releases still install Atet, not Slopcamera.
