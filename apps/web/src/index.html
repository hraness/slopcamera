Why install it

{{PRODUCT_HEADING_WHY}}

A one-shot reply writes the renderer, export code, and checks along with the scene, and the next request writes them all again. Here the agent writes only the source.

  1. {{PRODUCT_HEADING_WHY_SOURCE}}

    The agent writes diagram JSON, scene JSON, an HTML scaffold, or Blender, CadQuery, or Manim source. The CLI renders it and writes the variants each technique supports, such as light and dark diagrams or 16:9 and 9:16 cuts of a video.

    See the techniques

  2. {{PRODUCT_HEADING_WHY_CHECK}}

    A strict check names labels that overflow their boxes, shapes outside the canvas, and arrows too short to read. Scene checks validate the scene file, and scene audits sample what a named camera sees over time. The agent fixes the source before it renders.

    Check a first diagram

    The source stays beside every output. A change is an edit to that file and one command:

  source-to-film.diagram.json
    See the revised render

Your files

{{PRODUCT_HEADING_DESIGN}}

Slopcamera keeps editable source beside each render. Sources, edits, and local renders stay on your own storage; generation and selected cloud analysis use the services described below.

Source media stays unchanged
Original recordings and imported media stay unchanged. Cuts, framing, overlays, and effects remain project decisions.
Project state stays on your machine
There is no Slopcamera account or hosted project database. You control source, project state, previews, and final files.
Gateway credentials stay local
Local processes use your Vercel AI Gateway credential without storing or printing it. Media uploads require acknowledgement.
Operations leave a record
Important operations save a record of their inputs and outputs, with no secrets in it.

Native engine jobs run only with --allow-trusted-code. They and custom Bun workflows run as your current user, without an operating-system sandbox, so review their source first. Read the security policy and privacy guide.

FAQ

{{PRODUCT_HEADING_QUESTIONS}}

How is Slopcamera different from Remotion or HyperFrames?

Remotion renders React to video; HyperFrames renders HTML. Slopcamera combines HTML motion, diagrams, 3D and native scenes, and edits of your own footage in a local project. Compare their workflows and licensing, or read {{SHELL_PRODUCT_NAME}} vs Remotion and {{SHELL_PRODUCT_NAME}} vs HyperFrames.

Do I need to write code?

Describe the result to your coding agent; it writes the source and runs the commands.

Does Slopcamera require an account or subscription?

No. Slopcamera has no account or subscription. Generation uses your own Vercel AI Gateway account, or prepaid Hraness Credits for hosted image generation.

What does it cost?

Slopcamera is free; editing, diagrams, vectorization, and exports run locally. Model usage is billed to your Vercel AI Gateway account, or to prepaid Hraness Credits for hosted image generation.

Which platforms does Slopcamera run on?

Use Bun 1.3.14+ on macOS, Linux, or Windows. A few features are narrower: vectorization, local audio and color effects, and the native engines (Blender, CadQuery, and Manim) run on macOS and Linux, and the GPU scene profiles and face analysis need macOS. Import existing recordings; Slopcamera does not record your screen or camera. Run slopcamera doctor to check local tools and see the platform requirements.

Does Slopcamera overwrite original media?

Edits leave original recordings and imported media unchanged. Diagram renders replace only their named derived outputs.

When can local media leave the machine?

Editing and rendering stay local. Gateway generation and selected cloud analysis upload named media only after acknowledgement. Native Python and custom Bun workflows run with current-user access, including possible network access.

Which agents can use the skill, and how do I install it for Claude Code?

Use Codex, Claude Code, or an agent that reads ~/.agents/skills. Run slopcamera skill install for Codex, add --target claude for Claude Code, or --target agents for other agents.

Is Slopcamera the same as Atet?

Yes. Atet was renamed Slopcamera in September 2026, and atet.sh now redirects here. Old Atet releases still install Atet, not Slopcamera.
